# 2026 大三上学期工作台部署说明

## Netlify（最省事）

1. 打开 https://app.netlify.com/drop 并登录。
2. 将整个 `semester-workbench-deploy` 文件夹或 ZIP 压缩包拖入页面。
3. 等待生成 `netlify.app` 公开链接。

以后更新时，用新版文件夹重新拖到该站点的部署区域即可。

## GitHub Pages

1. 新建一个 GitHub 仓库。
2. 将本文件夹中的 `index.html` 和 `.nojekyll` 上传到仓库根目录。
3. 在仓库 `Settings` → `Pages` 中选择从分支部署，分支选 `main`，目录选根目录 `/`。
4. 保存并等待公开链接生成。

## 跨设备数据

- 勾选记录保存在浏览器本地，不会随公开链接自动同步。
- 换电脑前点击工作台中的“导出备份”，在新电脑打开同一链接后点击“导入备份”。
- 备份文件可能包含健康、成绩和求职信息，请不要公开上传该 JSON 文件。
- 如果以后需要自动同步，可再接入带登录权限的云数据库。
